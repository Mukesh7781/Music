🎵 Music Explorer — Flutter App



Music Explorer is a beautiful Flutter app that lets users explore and listen to songs from the iTunes API.

It features a clean Spotify-style UI with dark/light mode, shimmer loading, infinite scrolling, and favorites support — all built with Flutter and Provider.

A new Flutter project.

###### 🛠️ Tech Stack



Framework: Flutter (3.x or higher)

State Management: Provider

API: iTunes Search API

Storage: Local storage (SharedPreferences / custom LocalStorage service)

UI: Shimmer, gradients, and smooth animations



###### 1️⃣ Prerequisites



Ensure you have:

Flutter SDK (≥ 3.0.0)

Android Studio or VS Code with Flutter plugin

A connected emulator or physical device



###### 2️⃣ Clone the Repository:-

git clone https://github.com/your-username/music\_explorer.git

cd music\_explorer





###### 3️⃣ Install Dependencies:-


flutter pub get



###### 5️⃣ Run the App:-


For Android: flutter run
---

For IOS:- flutter run -d ios
